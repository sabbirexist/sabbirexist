## About

<div align="center">

I'm **Sabbir**, a **developer** and **video editor** from *Madaripur, Bangladesh*.

I build practical software — **Telegram automation**, **backend services**, **streaming platforms** and **web utilities** — with a focus on clean implementations, reliable workflows and tools that solve real problems.

Beyond development, I work in **Adobe Premiere Pro** and **After Effects**, combining technical thinking with visual storytelling.

Currently building, experimenting and contributing to open source through **Kodex** and projects across the Telegram ecosystem.

</div>
