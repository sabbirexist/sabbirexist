ABOUT

I'm Sabbir, a developer and video editor from Madaripur, Bangladesh.

I build practical software — from Telegram automation and backend services to streaming platforms and web utilities. My focus is on clean implementations, reliable workflows, and tools that solve real problems.

Beyond development, I work with Adobe Premiere Pro and After Effects, combining technical thinking with visual storytelling.

Currently building, experimenting, and contributing to open source through Kodex and projects across the Telegram ecosystem.
